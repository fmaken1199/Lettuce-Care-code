# Lettuce Care

Identify lettuce leaf diseases and view care recommendations.

Use Python 3.12. Extract the ZIP and open a terminal inside `pakistan_lettuce_dss`.

Install:

```bash
python -m pip install -r requirements.txt
```

Run:

```bash
python -m streamlit run app.py
```

On Windows, you can also double-click `run.bat` after installing.

Upload a leaf photo, check the crop settings, and select **Get recommendations**. Location and measured pH/EC are optional. Internet access is needed for weather and place search.

The selected model, treatment database and local soil maps are included. Keep the folder structure unchanged.
